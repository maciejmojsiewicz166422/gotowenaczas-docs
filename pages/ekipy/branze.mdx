# Branże

Aplikacja obsługuje ponad 30 branż budowlanych i zawodów. Każda branża ma gotowy
szablon umowy z zakresem prac i warunkami specyficznymi dla danego rodzaju robót.

## Branże budowlane

Ekipy wykonujące roboty budowlane na placu budowy:

| Branża | Przykładowe prace |
|---|---|
| Roboty ziemne | Wykopy, niwelacja terenu, odwodnienie |
| Beton | Fundamenty, stropy, schody żelbetowe |
| Murarz | Mury nośne, ścianki działowe, kominy |
| Cieśla (dach) | Konstrukcja dachu, więźba dachowa |
| Dekarz | Pokrycie dachowe, obróbki blacharskie |
| Tynkarz | Tynki wewnętrzne i zewnętrzne |
| Glazurnik | Płytki podłogowe i ścienne |
| Malarz | Malowanie ścian i sufitów |
| Hydraulik | Instalacja wod-kan, ogrzewanie podłogowe |
| Elektryk | Instalacja elektryczna, oświetlenie |
| Klimatyzacja i wentylacja | HVAC, rekuperacja |
| Ocieplenie | Izolacja termiczna, styropian, wełna |
| Elewacja | Tynk elewacyjny, okładziny |
| Okna i drzwi | Montaż okien, drzwi, bram |
| Podłogi | Wylewki, panele, parkiet |
| Ogrodzenie | Ogrodzenie, brama wjazdowa |
| Zagospodarowanie terenu | Podjazd, chodniki, zieleń |
| Wyburzenia | Rozbiórki, usuwanie gruzu |
| Suche zabudowy | Ścianki gipsowe, sufity podwieszane |
| Ślusarz | Balustrady, konstrukcje stalowe |
| Kominiarz | Przeglądy kominiarskie |

## Zawody i specjaliści

Osoby świadczące usługi profesjonalne (nie roboty budowlane):

| Zawód | Rodzaj umowy |
|---|---|
| Geodeta | Umowa o dzieło |
| Architekt | Umowa o dzieło |
| Projektant instalacji (MEP) | Umowa o dzieło |
| Kierownik budowy | Umowa zlecenia |
| Inspektor nadzoru | Umowa zlecenia |
| Audytor energetyczny | Umowa o dzieło |
| Rzeczoznawca majątkowy | Umowa o dzieło |
| Kominiarz (przegląd) | Umowa o dzieło |

> **Ważne:** Rodzaj umowy jest dobierany automatycznie na podstawie branży.
> Roboty budowlane → umowa o roboty budowlane. Specjaliści → umowa o dzieło lub zlecenia.
> Więcej w sekcji [Rodzaje umów](/umowy/rodzaje).

## Generalny wykonawca

Branża **Generalny wykonawca** obejmuje prace kilku ekip jednocześnie:
roboty ziemne, beton, murowanie, ciesielstwo dachowe i dekarstwo.

Jeśli zatrudniasz jedną firmę do całości stanu surowego, wybierz tę branżę —
szablon umowy uwzględni pełen zakres.

## Szablony i zakres prac

Każda branża (oprócz „Inna") ma gotowy szablon z punktami zakresu prac.
Przy tworzeniu umowy zaznaczasz odpowiednie punkty, a aplikacja wstawia je do treści umowy.

Szczegóły: [Szablony per branża](/umowy/szablony)
